# 全国 配車・積み合わせ最適化ダッシュボード（delivery-consolidation-vrp）

東京都内（1日15件程度）を中心に、大阪・愛知・福岡など主要都市、関東近郊、その他全国の配送依頼をひと月分まとめてダミー生成し、車のサイズ制限・付帯作業・時間指定といった現場の制約を踏まえたうえで、「バラバラに手配した場合」と「まとめて積み合わせた場合」の運賃差をブラウザ内でシミュレーションするダッシュボードです。

- **構成**: 単一 `index.html`。ブラウザで開くだけで動作（Tailwind CDNのためネット接続が必要）
- **GitHub**: https://github.com/Logtk/delivery-consolidation-vrp
- **デモ**: https://logtk.github.io/delivery-consolidation-vrp/ （`main` へ push すれば数分後に自動反映）

## 機能

1. **経営KPIカード（月間・全国）** — 全国の月間実績（件数・重量/容積・運賃）と、積み合わせによる削減額・削減率（年間換算付き）を一覧表示。東京都内と地方拠点を分けて確認できます
2. **表示日セレクタ（東京都内）** — 当月の営業日から1日を選び、その日の東京都内の配送に絞って詳しく確認できます
3. **車種別台数シフト比較グラフ** — 選んだ日について、個別に車を手配した場合とまとめて積んだ場合で、必要な車の台数・車種がどう変わるかをグラフで比較
4. **現場制約インサイトログ** — 車のサイズ制限で便を分けた理由、エリアをまたいでまとめた理由などを、選んだ日についてテキストで説明
5. **ルート別積載率詳細** — 便ごとの車種・件数・積み込み具合（重量・容積）・時間指定の有無などを一覧表示
6. **地方拠点サマリー** — 大阪・愛知・福岡・関東近郊・その他の道府県について、月間の件数・車両延べ台数・運賃をまとめて表示
7. **Excelデータシミュレーター** — 月間全地域分（1,200件超）の元データを日付・都道府県で絞り込んで一覧確認
8. **動的パラメーター** — 配送の時間帯にどれだけ余裕を持たせるか、付帯作業（荷卸しの手伝い等）にどれだけ時間がかかるかをスライダーで変えると、全国データがその場で再計算されます

## 計算の考え方

東京都内は、車の重さ・体積・時間指定などの制約を踏まえて配送依頼を1台ずつ詰め込んでいき、積載に余裕がある場合は近いエリア同士をまとめる、という考え方で計算しています。地方拠点は1日あたりの件数が少ないため、車のサイズ制限だけを考慮したシンプルな計算にしています。どちらも「1件ずつ個別に車を手配した場合」の運賃と比較して、削減額を算出しています。

配送件数・運賃はすべて架空の目安値をもとにしたダミーデータです（東京都内は1日平均15件、主要都市・近郊は1日平均3〜4件程度になるようランダムに生成）。計算ロジックの詳細は `index.html` 内のJavaScriptを参照してください。
